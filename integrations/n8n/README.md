# n8n adapter

n8n remains a thin personal automation adapter:

1. Validate the Telegram owner.
2. Maintain typing/progress and error messages.
3. Submit camera paths to the standalone engine.
4. Review chunked AI tasks using configured n8n credentials.
5. Finalize through the standalone engine and send outputs.

The adapter must never contain the edit algorithms. A user who does not install n8n can run the same engine from Hafez Studio Desktop.
