## Adapter and UI
`electron/upscale-worker.py`, `upscale-seed-bridge.py`, `upscale.js`; app section Upscale.
Vendor OpenCV uint8 decode/output was unsuitable for the owner's 10-bit source.
Own adapter reads FFmpeg RGB48 to float32 and writes float tensors through RGB48
to ProRes HQ yuv422p10le Rec.709. Model's internal FP16 math is unchanged.
HDR, wide gamut, interlace, non-square pixels, rotation and VFR are rejected instead
of silently conformed. No claim of HDR support. No 4K performance validation yet.

Five-second preview precedes full processing. Full processing requires same-input,
same-resolution successful preview and explicit owner quality confirmation.
Outputs go to a unique Upscale subfolder. Source is never overwritten. Audio is
stream copied and latest worker checks packet hashes and start-time preservation.
Checks include model hashes, source timestamps, frame count, FPS, dimensions,
available disk space and source file stability. Generative quality is still an
owner review, not guaranteed by these technical checks. Original MOGRTs stay editable.

Runtime is machine-local, not a portable redistributed model bundle. Candidate
references its installed runtime via `build/upscale-install.json`. Do not move or
delete that runtime. Existing application and desktop shortcut are unchanged.
